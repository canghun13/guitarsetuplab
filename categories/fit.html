How to use the Pickup fit & spacing bench

Start with the real guitar and the exact candidate drawing. Keep string path, pole centers, pickup envelope, cavity, ring opening, and screw spans as separate measurements.

Choose the right starting point

Project the string spread first, screen pole alignment second, then verify route and mounting geometry. A pass at one stage never implies a pass at the next.

This category contains 4 focused tools. Read each page’s preparation and limitation sections before entering values, then follow only the related workflow that resolves the next uncertainty.

Evidence standard

Use current manufacturer drawings and a physical overlay or mock-up. Stop for inaccessible measurements, close clearance, forced fit, drilling, routing, or any unmodeled protrusion.

  1. Preserve the starting condition.
  2. Change or test one variable.
  3. Retune or reset the test condition.
  4. Repeat the same measurement.
  5. Record remaining uncertainty.

When to stop

Stop when evidence conflicts, a datum is unclear, hardware reaches a limit, or the next step becomes structural, energized, or irreversible. A qualified technician can inspect conditions that browser inputs cannot represent.
