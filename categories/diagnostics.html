How to use the Diagnostics & setup bench

Start with the symptom, then locate where and when it occurs. The safest diagnostic path uses controlled comparisons before adjustment.

Choose the right starting point

Use Setup Wizard for an unknown sequence, the focused buzz, high-action, tuning, or intonation tools for a repeatable symptom, and the instrument checklists when a complete baseline is needed.

Evidence standard

A diagnosis remains provisional until a physical test confirms it. Record “not tested” rather than converting missing evidence into certainty.

  1. Preserve the starting condition.
  2. Change or test one variable.
  3. Retune or reset the test condition.
  4. Repeat the same measurement.
  5. Record remaining uncertainty.

When to stop

Stop when evidence conflicts, a datum is unclear, hardware reaches a limit, or the next step becomes structural, energized, or irreversible. A qualified technician can inspect conditions that browser inputs cannot represent.
