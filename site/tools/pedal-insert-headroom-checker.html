What this tool is for

Normalize dBu, dBV, and Vrms specifications to screen send peaks and return margin. Recording tools convert documented device specifications and measured waveform evidence into loading, level, headroom, and timing comparisons. They never authorize speaker-level connections or powered-device repair.

Use it when you can describe the current state and need a defensible next check. It is not a shortcut around inspection: preserve the starting state, change one variable, and verify the result under the same conditions.

Before you begin

Find nominal send/return levels and maximum pedal input/output from current documentation. Keep dBu, dBV, and Vrms labels attached to every value, and measure peak-above-nominal under the intended passage.

  • Use a stable, tuned instrument unless the page specifically investigates tuning.
  • Name the physical reference, unit, and test condition beside every important number.
  • Keep the original measurements so any reversible change can be returned to baseline.

How the result should be read

The input pass applies only to the headroom requirement you entered. Read output margin separately and check the return maximum specification, gain controls, noise, and clipping with the real devices.

Read priorities from top to bottom, but stop as soon as new evidence contradicts an earlier assumption. Save or print the result ticket with the entered conditions so another person can reproduce the decision.

Method and logic

All entered levels are normalized through Vrms and displayed in dBu. Send peak equals nominal plus the measured peak margin; input headroom is pedal maximum input minus send peak; output margin is pedal maximum output minus return nominal.

The page keeps calculation and diagnostic claims deliberately bounded. Display rounding improves readability, while the underlying logic uses entered values; descriptive branches report relative tendencies and the evidence needed to confirm them.

Worked example

A 0 dBu nominal send with peaks 6 dB higher reaches +6 dBu. Against a +12 dBu pedal maximum, 6 dB remains. A +8 dBu pedal output versus a +4 dBu return nominal has a 4 dB level margin, not a clipping guarantee.

The example demonstrates reasoning, not a universal setup specification. Substitute real measurements and repeat the final test before accepting the next action.

Assumptions and limitations

Nominal and maximum specifications are not interchangeable. Frequency response, impedance, balanced wiring, noise floor, pedal power, soft clipping, and undocumented peaks are not modeled.

Instrument design, service history, measurement error, and player technique can outweigh a calculator or checklist. Where manufacturer instructions exist for the exact hardware, use those instructions and record the revision consulted.

Safety and stop conditions

Turn monitoring and outputs down before changing connections. Never connect an amplifier speaker output to a DI, reamp box, pedal, microphone input, or audio interface unless the exact manufacturer documentation explicitly provides the compatible speaker-level load/input. Do not open an amplifier, power supply, or mains device. Stop for clipping, electrical sensation, heat, odor, damaged cables, unstable microphone stands, or a specification you cannot verify.
