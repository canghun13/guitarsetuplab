How to Measure Nut and Bridge String Spacing

Measure centers, edge gaps, gauges, and margins without mixing definitions.

Name the distance first

Center spacing runs from one string centerline to the next. Edge gap runs from the side of one string to the side of the next. Overall spread runs between the outer string centers; physical margins run from a part edge to a string edge or center.

Record real diameters

Measure or obtain the installed gauges, keep all values in one unit, and state whether the outside margin is to the outer string center or edge. Equal-center and equal-edge-gap layouts answer different questions.

Compare the nut and bridge planners before transferring marks.

Safety boundary Stop for abnormal resistance, cracking sounds, visible movement, electrical hazards, or measurements you cannot reproduce.
