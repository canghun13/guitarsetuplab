How to use the Recording & reamping bench

Begin with the signal path on paper and all outputs down. Identify whether each value is source impedance, input impedance, nominal level, maximum level, dBFS reading, sample position, or physical distance.

Choose the right starting point

Use DI loading before capture, reamp matching for a repeatable level baseline, pedal insert screening for external effects, round-trip alignment for electrical routing, and dual-mic planning for acoustic arrival.

This category contains 5 focused tools. Read each page’s preparation and limitation sections before entering values, then follow only the related workflow that resolves the next uncertainty.

Evidence standard

Preserve the unchanged reference recording, exact device and cable path, meter mode, sample rate, and current manufacturer documentation. A numerical pass is followed by a low-level physical verification.

  1. Preserve the starting condition.
  2. Change or test one variable.
  3. Retune or reset the test condition.
  4. Repeat the same measurement.
  5. Record remaining uncertainty.

When to stop

Stop when evidence conflicts, a datum is unclear, hardware reaches a limit, or the next step becomes structural, energized, or irreversible. A qualified technician can inspect conditions that browser inputs cannot represent.
