Scope of this reference

Convert common millimetre and inch measurements used at the bench. Use Guitar Setup Unit Conversion Reference to make a repeatable decision for this named task, not to impose one specification on every instrument.

Practical example

A measured 1.6 mm action is about 0.0630 inch and close to 4/64 inch. Keep 1.6 mm as the observed value if that matches the tool resolution; the fraction is a communication aid and does not add precision.
