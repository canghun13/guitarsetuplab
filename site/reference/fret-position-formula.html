Fret Position Formula Reference

Define cumulative 12-TET fret coordinates, adjacent spacing, scale length, and compensation boundaries.

Equal-tempered coordinate

d = s - s / 2^(n/12), where s is nominal scale length, n is fret number, and d is the distance from the nut witness point to that fret.

At fret 12, d = s/2. Adjacent slot spacing is the current cumulative coordinate minus the previous coordinate. Saddle compensation changes the practical string endpoint; it does not change the nominal fret formula.
