Guitar Control Hardware Dimension Reference

Define holes, threaded stacks, shafts, component envelopes, service space, and harness coordinates.

Mounting hole / slot
The smallest clear opening the candidate bushing or mounting section must pass through.
Panel stack
Every layer crossed by the threaded section: top, pickguard, plate, finish, washers, and any named spacer.
Threaded bushing length
The usable threaded section, not total shaft length or component body height.
Shaft interface
Diameter, solid/split construction, smooth or spline form, and usable height above the mounted surface.
Component envelope
Body plus terminals, wire bend, connector, switch travel, or plug projection as separate measured requirements.
Harness coordinates
Hole-center x,y values recorded from one origin with the same axis direction for existing and candidate layouts.
Allowance
User-entered free space reserved for insulation, wire bend, service, finish, or measurement uncertainty.

A nominal component name does not replace current maker dimensions. Follow the measurement guide and verify with a physical overlay or dry fit.

Scope of this reference

Define holes, threaded stacks, shafts, component envelopes, service space, and harness coordinates. Use Guitar Control Hardware Dimension Reference to make a repeatable decision for this named task, not to impose one specification on every instrument.

Practical example

Bushing diameter is not mounting-hole diameter, shaft diameter is not knob bore, and jack body depth is not its installed envelope with a plug. A useful part drawing names each datum and includes tolerances or leaves the uncertainty explicit.
