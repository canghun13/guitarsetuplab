Guitar Setup Measurement Points

A reference for recording where and how each setup measurement was taken.

Relief
Gap near mid-span while the string is held at the first and last fret/body joint.
Action
Gap from fret crown to string underside at a named fret.
Pickup clearance
Gap from pole/top to string underside while fretting the last fret.
Scale
Twice nut-to-12th-fret is the nominal scale; saddle positions include compensation.

Scope of this reference

A reference for recording where and how each setup measurement was taken. Use Guitar Setup Measurement Points to make a repeatable decision for this named task, not to impose one specification on every instrument.

Practical example

“Action 2.0 mm” is incomplete until the record says which fret, which string, top of fret to underside of string, tuning, and instrument position. The same discipline applies to relief span, pickup clearance at the last fret, and scale witness points.

Record the conditions

For Guitar Setup Measurement Points, write down instrument type, tuning, installed strings, relevant hardware, climate when material, physical datum, unit, tool resolution, and the result before and after change. A result from this reference is comparable only when its method travels with the number.

Verification checklist

  1. For Guitar Setup Measurement Points, confirm the starting state and exact question.
  2. Repeat its critical measurements from the same reference.
  3. Compare its result with direct observation and applicable maker documentation.
  4. Change one reversible variable where the task permits.
  5. Retest the named symptom and preserve unresolved exceptions.

Limits

Guitar Setup Measurement Points cannot inspect hidden structure, material condition, service history, or player technique. Stop this reference workflow for electrical hazards, abnormal resistance, structural movement, conflicting readings, or unplanned material removal.
