Choosing Guitar Pot and Capacitor Values

Compare pickup loading and tone-control ranges without promising an exact sound.

Pot value changes loading

For passive pickups, a higher resistance usually loads the pickup less and tends to preserve more high-frequency response. Cable capacitance, pickup inductance, control taper, wiring, and amplifier input all shape the result.

Capacitor value changes the roll-off range

A larger tone capacitor generally permits a darker fully-rolled-off sound. A simple RC cutoff is only a reference because a guitar pickup is not an ideal voltage source.

Scope of this guide

Compare pickup loading and tone-control ranges without promising an exact sound. Use Choosing Guitar Pot and Capacitor Values to make a repeatable decision for this named task, not to impose one specification on every instrument.

Practical example

A 500 kΩ pot generally loads a passive pickup less than a 250 kΩ pot, while a 47 nF tone capacitor usually allows a darker rolled-off range than 22 nF. Neither comparison predicts exact sound because pickup inductance, cable capacitance, tolerance, and amplifier input remain in the circuit.
