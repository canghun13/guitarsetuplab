What this tool is for

Compare equal-center and equal-edge-gap nut layouts from real string diameters. Geometry tools apply explicit models to named measurements. A coordinate or angle must still be checked against a physical drawing, real hardware, tolerances, and material behavior.

Use it when you can describe the current state and need a defensible next check. It is not a shortcut around inspection: preserve the starting state, change one variable, and verify the result under the same conditions.

Before you begin

Measure nut width and define whether outside margins reference string edges or centers. Enter installed string diameters in one unit and choose equal-center or equal-gap layout.

  • Use a stable, tuned instrument unless the page specifically investigates tuning.
  • Name the physical reference, unit, and test condition beside every important number.
  • Keep the original measurements so any reversible change can be returned to baseline.

How the result should be read

Compare both tables and verify outer-string clearance over fret bevels on the actual neck. Transfer center marks only after the physical margin definition is confirmed.

Read priorities from top to bottom, but stop as soon as new evidence contradicts an earlier assumption. Save or print the result ticket with the entered conditions so another person can reproduce the decision.

Method and logic

Equal-center divides outer-center spread evenly. Equal-gap subtracts string radii and distributes open space so adjacent edge gaps match despite mixed gauges.

The page keeps calculation and diagnostic claims deliberately bounded. Display rounding improves readability, while the underlying logic uses entered values; descriptive branches report relative tendencies and the evidence needed to confirm them.

Worked example

For six mixed gauges, equal-center produces identical center intervals but visibly tighter open space beside the heavy strings. Switching to equal-gap changes the center coordinates while preserving chosen outer references.

The example demonstrates reasoning, not a universal setup specification. Substitute real measurements and repeat the final test before accepting the next action.

Assumptions and limitations

No calculator supplies a universal edge margin, ergonomic preference, slot width, or safe cutting depth. Real gauges, fret bevel, player technique, and nut material matter.

Instrument design, service history, measurement error, and player technique can outweigh a calculator or checklist. Where manufacturer instructions exist for the exact hardware, use those instructions and record the revision consulted.

Safety and stop conditions

Stop for abnormal resistance, cracking, heat, odor, electrical sensation, moving wood or joints, a measurement that cannot be repeated, or any step that would remove material without a confirmed cause. Secure strings and stored mechanical energy before hardware work. Refer structural, fret-cutting, mains-powered, or uncertain repairs to a qualified technician.
