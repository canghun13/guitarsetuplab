Outputs: compatibility inventory, dataset findings, split audit, residual metrics and performance result. [Core](https://github.com/sdatkinson/NeuralAmpModelerCore) already includes loadmodel/benchmodel; native benchmarks are not evidence for another runtime. [A2 author](https://www.neuralampmodeler.com/post/architecture-a2) discusses data/evaluation and hardware-dependent compute. [NAM Inspector](https://showtheworking.com/nam-inspector) exposes a free local file input, architecture/rate/weight readout, not playback or sound certification. File inspection is occupied; sample/dataset checks are promising but partition/residual checks share evaluation logic and a weight-count “CPU prediction” is not a fourth defensible hardware Tool. D/F/I unresolved; C only partial. No amplifier internals, capture-power wiring or architecture conversion claim.
2. **DAW sessions.** Inputs: project/interchange files, media inventory, host/plugin IDs and timeline constraints. Outputs: dependency manifest, relink candidates, handoff map, timeline/graph findings. [NoirSonance](https://noirsonance.com/daw-project-converter/) exposes a free local project bridge and manifest/CSV/basicRPP export; it explicitly excludes proprietary native formats, plugin state and complex automation. No files/accounts uploaded or licence bypass attempted.
3. **Sampler preflight.** Inputs: SFZ and selected sample folder, intended key/velocity/trigger contexts and engine. Outputs: mapping/dependency/sequence findings and player-specific checks. Seven searched questions collapse toward one semantic auditor plus an audition engine, not seven independent Tools; C/D fail for a new cluster.
